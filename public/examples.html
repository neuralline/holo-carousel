HOLO examples

Every demo below runs the code under it. Copy it into a page that has Cyre and Holo.

Setup

Cyre is a peer dependency: install both, they share one Cyre.

npm i cyre holo-carousel

import {useHolo} from 'holo-carousel'
const holo = useHolo()
const el = document.querySelector('#my-carousel')   // an empty <div> for data mode
